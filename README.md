# Software Developmen Basic

software တစ်ခု စရေးတဲ့အခါ ဘာတွေ မျှော်လင့်ထားတယ်။
ဘာတွေ လုပ်ရမယ်။
ဘယ်စည်းမျဉ်းစည်းကမ်းတွေကို လိုက်နာရမယ်။

ဒါတွေကို တစ်နေရာတည်းမှာ စုပြီး ရေးထားမယ့် repo ပါ။

အဓိက ရေးသွားမှာက

RESTFUL API ကိုယ် ဘယ်လို လိုချင်တယ်။
API Integration မှာ UI ကို ဘယ်လို behaviour ရှိစေချင်တယ်
စသည်ဖြင့် အခြေခံ လိုက်နာရမယ့် မျှော်လင့်ချက်တွေကို ချရေးသွားမယ်။

Theory အပိုင်းဆိုပေမယ့် Implementation ကို Laravel , React , Flutter သုံးပြီး ရေးသွားဖို့ စီစဉ်ထားတယ်။
တက်နိုင်သမျှ programming language, framework အပေါ် မှီခိုတာမျိုး မလုပ်ပဲ ဘယ် အေအိုင် ဘယ် ပရိုဂရမ်မာမဆို လိုက်နာနိုင်မယ့် ပုံစံဖြစ်အောင် ရေးထားမယ်။
